# 월드뷰

**다양한 이미지와 압축 파일, PDF 문서를 빠르고 편리하게 보는 Windows 무료 이미지 뷰어.**

## 개요

폴더 가득한 사진을 넘겨 보고, 만화책 압축 파일을 풀지 않고 두 장씩 펼쳐 읽고, 웹툰을 세로로 이어 내려 읽는 이미지 뷰어입니다. PDF 문서도 한 쪽씩 같은 방식으로 봅니다.

이미지를 창에 끌어다 놓으면 바로 열리고, 같은 폴더의 다른 이미지가 순서대로 이어집니다. 화면에는 그림만 보이고, 버튼은 마우스를 창 위·아래로 가져갈 때만 나타납니다.

그래픽 카드로 그림을 그려 큰 사진도 부드럽게 확대·축소하고, 앞뒤 장을 미리 읽어 두어 넘길 때 기다림이 적습니다.

## 주요 기능

- **다양한 이미지 형식** — JPEG, PNG, GIF, WebP, TIFF, BMP, SVG, JPEG XL, HEIC, AVIF, PSD, 카메라 RAW 등.
- **압축 파일을 풀지 않고 보기** — ZIP, RAR, 7Z, CBZ, CBR, EGG, ALZ 등의 안에 든 그림을 한 장씩 넘겨 봅니다.
- **PDF 문서** — 쪽마다 한 장으로 넘겨 보고, 확대하면 그 크기로 다시 그려 글자가 선명합니다.
- **네 가지 보기 방식** — 한 장씩, 두장 보기(왼→오 / 오→왼), 첫 페이지 표지, 웹툰 이어보기.
- **움직이는 이미지** — GIF · APNG · 움직이는 WebP 를 재생합니다.
- **자동 회전과 색 보정** — 세로로 찍은 사진은 바로 서서 열리고, 색 프로파일이 있는 사진은 원래 색으로 보입니다.
- **확대와 전체보기** — 커서 위치를 기준으로 확대하고, 넘치는 그림은 오른쪽 아래 전체보기로 원하는 곳에 바로 갑니다.
- **이미지 정보와 EXIF** — `Tab` 한 번으로 파일 정보와 촬영 시각·카메라·렌즈·노출을 봅니다.
- **편리한 기능** — 파일 연결, 전체 화면, 항상 위, 최근 파일, 마지막으로 보던 장부터 다시 열기, 휴지통으로 삭제, 단축키 변경.
- **8개 언어** — 한국어 · 영어 · 일본어 · 중국어 · 러시아어 · 이탈리아어 · 프랑스어 · 스페인어.

## 다운로드 / 설치

| 종류 | 링크 |
|---|---|
| 설치판 | [다운로드](https://down.kilho.net/worldview?lang=ko) |
| 무설치판 (ZIP) | [다운로드](https://down.kilho.net/worldview?lang=ko&nosetup) |

설치판은 설치가 끝나면 월드뷰를 바로 엽니다. 무설치판은 ZIP 을 풀고 `WorldView.exe` 를 실행하면 됩니다 — `vendor` 폴더는 실행 파일과 같은 곳에 두어야 합니다. 설정은 프로그램 폴더에 저장되므로, 무설치판을 USB 에 넣어 다니면 설정도 함께 따라갑니다.

설치판도 파일 연결은 하지 않습니다. 이미지를 더블클릭해 월드뷰로 열고 싶으면 **환경설정 → 연결** 에서 켜세요(아래 「이럴 때 이렇게」 참고).

## 사용법

### 처음 사용하기

1. 월드뷰를 실행하고 이미지 파일, 폴더, 압축 파일, PDF 중 하나를 창에 끌어다 놓습니다. 하단 바의 폴더 버튼이나 `O` 키로 파일을 골라도 됩니다.
2. 고른 이미지가 창에 맞춰 열리고, 같은 폴더의 다른 이미지가 이름 순서대로 목록이 됩니다. 창 위쪽 제목에 `폴더 > 파일 이름 [69/308]` 처럼 지금 위치가 나옵니다.
3. 마우스 휠을 굴리거나 `←` `→` · `PageUp` `PageDown` 을 누르면 이전·다음 장으로 넘어갑니다. 마우스를 창 좌우로 가져가면 나오는 화살표 버튼을 눌러도 됩니다.
4. 마우스를 창 아래로 가져가면 하단 바가 나타납니다. 확대·축소·회전 버튼과 탐색바가 있고, 탐색바를 끌면 원하는 장으로 바로 갑니다.
5. 하단 바 오른쪽의 **보기** 버튼으로 배율(창에 맞춤·원본 크기·폭·높이)과 보기 방식(한 장·두장·웹툰)을 고릅니다. 고른 것은 기억되어 다음 장과 다음 실행에도 그대로입니다.
6. 창 어디서나 **마우스 오른쪽 클릭**을 하면 파일 열기·최근 파일·탐색기에서 보기·파일 삭제·환경설정 메뉴가 나옵니다.

### 이럴 때 이렇게

**폴더의 사진을 차례로 넘겨 보기**
사진 하나를 끌어다 놓거나 더블클릭하면, 그 폴더의 이미지가 이름 순서대로 목록이 됩니다. `사진2.jpg` 가 `사진10.jpg` 보다 먼저 오도록 숫자를 숫자답게 정렬합니다. 휠 · `←` `→` · `PageUp` `PageDown` · `Space` 로 넘기고, `Home` `End` 로 첫 장과 마지막 장에 갑니다.

**만화책 압축 파일을 풀지 않고 보기**
ZIP · RAR · 7Z · CBZ · CBR 같은 압축 파일을 그대로 끌어다 놓으면, 안에 든 그림이 한 장씩 넘겨집니다. 압축을 풀 필요도 임시 폴더도 없습니다. 압축 안의 폴더 구조도 이름 순서대로 이어서 보여 줍니다.

**책장 폴더를 통째로 보기**
폴더를 끌어다 놓으면 하위 폴더까지 모두 훑고, 그 안의 압축 파일과 PDF 도 한 장 한 장으로 펼쳐 하나의 목록으로 만듭니다. 권마다 따로 열 필요 없이 처음부터 끝까지 이어서 넘길 수 있습니다.

**여러 개를 골라 그것만 보기**
탐색기에서 파일·폴더·압축 파일을 여러 개 골라 한꺼번에 끌어다 놓으면, 고른 것만 목록이 됩니다. 고르지 않은 옆 파일은 들어오지 않습니다.

**만화책을 두 장씩 펼쳐 보기**
**보기** 버튼 → **두장 보기(왼쪽→오른쪽)** 를 고르면 책처럼 두 장이 나란히 펼쳐집니다. 오른쪽에서 왼쪽으로 읽는 일본 만화는 **두장 보기(왼쪽←오른쪽)** 를 고르세요. 장수가 홀수여도 마지막 장이 혼자 커지지 않고 반쪽 자리를 지킵니다.

**표지 때문에 짝이 어긋날 때**
두장 보기에서 1쪽이 표지라 펼친 면이 한 칸씩 밀려 보이면 **첫 페이지를 표지로 사용** 을 켜세요. 표지는 혼자, 그다음부터 2·3쪽, 4·5쪽으로 짝이 맞춰집니다.

**펼침 그림(양면 삽화)이 섞인 만화책**
**가로로 넓은 장은 단독으로** 를 켜면, 두 쪽을 한 장으로 스캔한 가로로 넓은 그림은 혼자 크게 보여 주고 나머지는 계속 두 장씩 짝을 맞춥니다.

**웹툰을 세로로 이어 읽기**
**보기** → **웹툰 보기** 를 켜면 모든 장이 창 폭에 맞춰 세로로 이어져 휠만 굴리면 끊김 없이 내려갑니다. 오른쪽 스크롤바를 끌어 전체에서 원하는 곳으로 바로 갈 수 있습니다.

**세로로 아주 긴 이미지 한 장**
세로가 가로의 3배를 넘는 이미지는 자동으로 폭에 맞춰 **맨 위부터** 열립니다. 휠·`↑` `↓`·`Space` 로 내려 읽다가 바닥에 닿아도 다음 장으로 튀지 않으니, 읽던 자리를 잃지 않습니다. 다음 장은 `PageDown` 이나 화살표 버튼으로 넘깁니다. `Ctrl`+`Home` / `Ctrl`+`End` 는 그 이미지의 맨 위·맨 아래로 한 번에 갑니다.

**PDF 문서를 한 쪽씩 보기**
PDF 를 끌어다 놓으면 쪽마다 한 장으로 넘겨집니다. 두장 보기로 책처럼 펼치거나 웹툰 보기로 이어서 내려 볼 수도 있습니다. 확대하거나 창을 키우면 그 크기로 다시 그려 작은 글자도 선명하고, 배경은 흰색이라 어두운 테마에서도 잘 읽힙니다.

**큰 사진을 확대해 구석구석 보기**
`Ctrl`+휠을 굴리면 **커서가 있는 곳을 중심으로** 확대·축소됩니다. `+` `-` 키나 하단 버튼으로도 됩니다. 확대한 그림은 끌어서 옮기고, `Shift`+휠로 가로로 움직입니다. 그림이 창보다 크면 오른쪽 아래에 **전체보기** 가 떠서 지금 보는 자리를 사각형으로 보여 주며, 누르거나 끌면 그 자리로 바로 갑니다. 확대하면 원본을 다시 읽어 세밀한 부분까지 선명하게 보입니다.

**전체보기를 가리고 싶을 때**
전체보기에 마우스를 올리면 나오는 X 를 누르면 꺼집니다. 다시 켜려면 **환경설정 → 보기 → 전체보기 보기** 를 켜세요.

**배율을 빠르게 바꾸기**
`1` 창에 맞춤, `2` 원본 크기, `3` 폭 맞춤, `4` 높이 맞춤입니다. 고른 배율은 다음 장에도, 다음 실행에도 그대로 이어집니다. 가로로 긴 스캔을 폭에 맞춰 읽거나, 사진을 늘 원본 크기로 확인하고 싶을 때 한 번만 고르면 됩니다.

**사진의 촬영 정보 확인**
`Tab` 을 누르면 화면 왼쪽 위에 파일 이름 · 파일 크기 · 수정한 날짜 · 이미지 정보가 나오고, 사진에 EXIF 가 있으면 촬영 시각 · 카메라 · 렌즈 · 노출 · 초점 거리 · 플래시 · 위치(GPS) 도 함께 나옵니다. 값이 있는 줄만 보여 줍니다. 두장 보기에서는 두 장의 정보가 각자의 반쪽에 따로 나옵니다. 다시 `Tab` 을 누르면 사라집니다.

**아이폰 사진(HEIC)이나 카메라 RAW, 포토샵 파일 열기**
HEIC · AVIF · JPEG XL, Canon · Nikon · Sony · Olympus · Pentax · Panasonic 의 RAW, 포토샵 PSD 도 다른 이미지처럼 끌어다 놓으면 열립니다. 사진은 찍은 방향대로 바로 서서 열리고, 색 프로파일이 들어 있으면 원래 색으로 보입니다.

**움직이는 GIF · WebP 보기**
한 장 보기에서 움직이는 GIF · APNG · WebP 를 열면 그대로 재생됩니다. 두장 보기와 웹툰 보기에서는 첫 장면만 보여 줍니다.

**보면서 사진 정리하기**
마음에 들지 않는 사진에서 `Delete` 를 누르면 확인 창이 뜨고, **예** 를 누르면 휴지통으로 보냅니다. 완전히 지우는 것이 아니라 휴지통에서 되살릴 수 있습니다. 확인 창이 번거로우면 **환경설정 → 일반 → 파일 삭제 시 한번 더 확인하기** 를 끄세요. 폴더의 파일에만 동작하며, 압축 파일 속 그림은 건드리지 않습니다.

**지난번에 보던 곳에서 이어 보기**
월드뷰를 그냥 실행하면 지난번에 보던 목록과 장이 그대로 열립니다. 다 읽지 못한 만화책도 그 쪽부터 이어집니다. 최근에 연 5개는 오른쪽 클릭 → **최근 파일** 에서 고를 수 있습니다. 매번 빈 창으로 시작하고 싶으면 **시작할 때 마지막 파일 열기** 를 끄세요.

**전체 화면으로 감상하기**
`Enter` 를 누르거나 제목 줄의 `[]` 를 누르면 작업 표시줄까지 덮는 전체 화면이 됩니다. `Esc` 나 `Enter` 로 돌아옵니다. 전체 화면에서 `Esc` 는 프로그램을 끄지 않고 전체 화면만 풉니다.

**다른 창 위에 띄워 두고 참고하기**
제목 줄의 압정을 누르면 **항상 위** 가 켜져 다른 프로그램을 쓰는 동안에도 월드뷰가 가려지지 않습니다. 그림을 보며 따라 그리거나 문서를 옆에 두고 작업할 때 좋습니다.

**두 이미지를 나란히 비교하기**
월드뷰를 하나 더 실행하면 새 창이 앞 창과 겹치지 않도록 살짝 비켜서 열립니다. 창을 나란히 놓고 비교하면 됩니다.

**마지막 장에서 처음으로 돌아가기**
기본은 마지막 장에서 더 넘기면 멈추고 화면에 `마지막 이미지입니다` 라고 알려 줍니다. 슬라이드처럼 계속 돌려 보고 싶으면 **환경설정 → 보기 → 처음/마지막 파일에서** 를 **처음으로 돌아가기** 로 바꾸세요.

**이미지를 더블클릭하면 월드뷰로 열리게 하기**
**환경설정 → 연결** 에서 월드뷰로 열 확장자를 체크합니다(**전체 선택** 도 있습니다). JPG · PNG · GIF · WebP · TIFF · BMP · TGA · PSD · JPEG 2000 · DDS · PCX · PDF · CBZ · CBR 을 고를 수 있고, 같은 형식(`.jpg` `.jpeg` `.jfif`)은 한 칸으로 묶여 있습니다. 칸 옆에 **적용안됨** 이 보이면 Windows 가 다른 프로그램을 우선하고 있다는 뜻입니다 — 그 표시를 누르면 해당 확장자의 기본 앱 선택 창이 열리니 월드뷰를 고르세요. 월드뷰를 제거하면 연결도 원래대로 돌아갑니다.

**단축키를 내 손에 맞게 바꾸기**
**환경설정 → 단축키** 에서 바꿀 동작의 키 칸을 누르고 새 키를 누릅니다. `Ctrl` · `Shift` · `Alt` 조합도 됩니다. `Backspace` 는 기본값으로 되돌리고, `Esc` 는 취소입니다. 다른 동작이 이미 쓰는 키는 받지 않고 어디에 쓰이는지 알려 줍니다.

| 동작 | 기본 키 |
|---|---|
| 창에 맞춤 · 원본 크기 · 폭 맞춤 · 높이 맞춤 | `1` · `2` · `3` · `4` |
| 오른쪽으로 90도 회전 | `R` |
| 이미지 정보 보이기/숨기기 | `Tab` |
| 전체화면 켜기/끄기 | `Enter` |
| 파일 열기 · 폴더 열기 | `O` · `Ctrl`+`O` |

이전·다음 장(`PageUp` `PageDown`), 첫·마지막 장(`Home` `End`), 확대·축소(`+` `-`), 휴지통(`Delete`), 그리고 방향키 · `Space` · `Esc` 는 고정입니다.

**창을 옮기고 크기 바꾸기**
그림 바깥의 빈 곳이나 창에 맞춰 보는 그림을 끌면 창이 옮겨지고, 가장자리를 끌면 크기가 바뀝니다. 마우스 가운데 버튼으로 끌어도 창이 옮겨집니다. 창의 위치와 크기는 기억되어 다음에 같은 자리에서 열립니다.

**지금 보는 파일이 어디 있는지 찾기**
오른쪽 클릭 → **탐색기에서 보기** 를 누르면 탐색기가 열리고 그 파일이 선택되어 있습니다. 파일 이름을 바꾸거나 복사할 때 편리합니다.

**화면을 더 깔끔하게**
**환경설정 → 보기** 에서 **스크롤바 보기** 와 **화면 좌/우 화살표 버튼 보기** 를 끄면 그림 위에 뜨는 것이 줄어듭니다. 끄더라도 휠 · 방향키 · 끌기로 똑같이 움직이고 넘길 수 있습니다.

## 설정

**환경설정** 에서 바꾼 값과 화면보기 메뉴에서 고른 배율·보기 방식은 자동으로 저장되어 다음 실행에도 그대로 쓰입니다.

| 항목 | 기본값 |
|---|---|
| 배율 | 창에 맞춤 |
| 보기 방식 | 한 장씩 |
| 첫 페이지를 표지로 사용 · 가로로 넓은 장은 단독으로 | 사용안함 |
| 스크롤바 · 전체보기 · 좌/우 화살표 버튼 · 정보에 EXIF | 사용함 |
| 처음/마지막 파일에서 | 멈춤 |
| ESC키로 프로그램 종료하기 · 파일 삭제 시 한번 더 확인하기 | 사용함 |
| 시작할 때 마지막 파일 열기 | 사용함 |
| 항상 위 · 로그 사용 | 사용안함 |
| 언어 | 시스템 설정 (Windows 지역 설정을 따르고, 지원하지 않는 언어면 영어) |

## 요구 사항

- Windows 10 · Windows 11 (64비트)
- 이미지를 여는 데 필요한 구성 요소가 모두 들어 있어 따로 설치할 것이 없습니다. 실행에 관리자 권한이 필요하지 않습니다.
- 인터넷 연결은 새 버전 안내에만 씁니다. 모든 이미지는 PC 안에서 열립니다.

## 概述

WorldView 可以翻看满满一文件夹的照片,不解压就能两页并排阅读漫画压缩包,还能把条漫竖着连成一条往下滚动阅读。PDF 文档也能用同样的方式一页一页地看。

把图片拖到窗口上就会立即打开,同一文件夹里的其他图片会按顺序接在后面。画面上只显示图片,按钮只在鼠标移到窗口上边或下边时才会出现。

由显卡负责绘制,大照片也能流畅地放大缩小;前后页会提前读好,翻页时几乎不用等待。

## 主要功能

- **多种图片格式** — JPEG、PNG、GIF、WebP、TIFF、BMP、SVG、JPEG XL、HEIC、AVIF、PSD、相机 RAW 等。
- **不解压直接看压缩包** — 逐张翻看 ZIP、RAR、7Z、CBZ、CBR、EGG、ALZ 等压缩包里的图片。
- **PDF 文档** — 每页作为一张图翻看,放大时按该尺寸重新绘制,文字清晰。
- **四种显示方式** — 单页、双页(左→右 / 右→左)、首页作为封面、条漫连续阅读。
- **动态图片** — 播放 GIF · APNG · 动态 WebP。
- **自动旋转与色彩校正** — 竖着拍的照片会以正确方向打开,带色彩配置文件的照片显示原本的颜色。
- **放大与导航图** — 以光标位置为中心放大;图片超出窗口时,可通过右下角的导航图直接跳到任意位置。
- **图像信息与 EXIF** — 按一下 `Tab` 即可查看文件信息以及拍摄时间、相机、镜头、曝光。
- **实用功能** — 文件关联、全屏、总在最前、最近的文件、从上次看到的页面继续、删除到回收站、自定义快捷键。
- **8 种语言** — 韩语 · 英语 · 日语 · 中文 · 俄语 · 意大利语 · 法语 · 西班牙语。

## 使用方法

### 基本流程

1. 运行 WorldView,把图片文件、文件夹、压缩包或 PDF 拖到窗口上。也可以用底部栏的文件夹按钮或 `O` 键选择文件。
2. 选中的图片按窗口大小打开,同一文件夹里的其他图片按名称顺序组成列表。窗口顶部的标题会显示当前位置,例如 `文件夹 > 文件名 [69/308]`。
3. 滚动鼠标滚轮,或按 `←` `→` · `PageUp` `PageDown` 切换到上一页或下一页。把鼠标移到窗口左右两侧时出现的箭头按钮也可以点。
4. 把鼠标移到窗口底部会出现底部栏。上面有放大、缩小、旋转按钮和进度条,拖动进度条可直接跳到任意一页。
5. 用底部栏右侧的 **查看** 按钮选择缩放(适应窗口·原始大小·宽度·高度)和显示方式(单页·双页·条漫)。所选内容会被记住,下一页和下次启动时依然生效。
6. 在窗口任意位置 **右键单击**,会出现打开文件·最近的文件·在资源管理器中显示·删除文件·设置等菜单。

### 这种情况怎么办

**按顺序翻看文件夹里的照片**
拖入或双击一张照片,该文件夹里的图片就会按名称顺序组成列表。数字按数值排序,所以 `照片2.jpg` 排在 `照片10.jpg` 前面。用滚轮 · `←` `→` · `PageUp` `PageDown` · `Space` 翻页,用 `Home` `End` 跳到第一页和最后一页。

**不解压直接看漫画压缩包**
把 ZIP · RAR · 7Z · CBZ · CBR 等压缩包直接拖进来,里面的图片就能一张张翻看。不需要解压,也不需要临时文件夹。压缩包里的文件夹结构也会按名称顺序连续显示。

**整个书架文件夹一起看**
拖入文件夹后,会扫描所有子文件夹,并把其中的压缩包和 PDF 也逐页展开,合成一个列表。不用一卷一卷地分别打开,就能从头翻到尾。

**只看挑选出来的几项**
在资源管理器中选中多个文件、文件夹或压缩包一起拖进来,列表里就只有所选的内容。没有选中的相邻文件不会混进来。

**两页并排看漫画**
选择 **查看** 按钮 → **双页显示(左→右)**,两页就会像书一样并排展开。从右往左读的日本漫画请选择 **双页显示(左←右)**。即使页数为奇数,最后一页也会保持半边的位置,不会突然变大。

**封面导致配对错位时**
双页显示时,如果因为第 1 页是封面而每一对都错开一页,请开启 **首页作为封面**。封面单独显示,之后按 2·3 页、4·5 页配对。

**夹有跨页插图的漫画**
开启 **横向页面单独显示** 后,把两页扫成一张的横向宽图会单独放大显示,其余页面仍然两两配对。

**把条漫竖着连起来读**
开启 **查看** → **条漫连续阅读** 后,所有页面按窗口宽度竖向相连,只要滚动滚轮就能一直往下看。拖动右侧滚动条可直接跳到整体中的任意位置。

**一张竖向很长的图片**
高度超过宽度 3 倍的图片会自动适应宽度,并 **从最上面** 打开。用滚轮 · `↑` `↓` · `Space` 往下读,到底也不会跳到下一页,不会丢失阅读位置。要看下一页,用 `PageDown` 或箭头按钮。`Ctrl`+`Home` / `Ctrl`+`End` 一次跳到该图片的最上面或最下面。

**逐页查看 PDF 文档**
拖入 PDF 后,每页作为一张图翻看。也可以用双页显示像书一样展开,或用条漫模式连续往下看。放大或把窗口拉大时会按该尺寸重新绘制,小字也很清晰;背景为白色,在深色主题下也易于阅读。

**放大大照片查看细节**
`Ctrl`+滚轮以 **光标所在位置为中心** 放大缩小。也可以用 `+` `-` 键或底部按钮。放大后的图片可以拖动,`Shift`+滚轮可左右移动。图片比窗口大时,右下角会出现 **导航图**,用方框标出当前查看的区域;点击或拖动即可直接跳到那里。放大时会重新读取原图,细节依然清晰。

**想隐藏导航图时**
把鼠标移到导航图上,点击出现的 X 即可隐藏。要重新显示,请在 **设置 → 查看 → 显示导航图** 中开启。

**快速切换缩放**
`1` 适应窗口,`2` 原始大小,`3` 适应宽度,`4` 适应高度。所选缩放会沿用到下一页和下次启动。想总是按宽度阅读横向扫描件,或总是以原始大小查看照片,只需选一次。

**查看照片的拍摄信息**
按 `Tab` 后,画面左上角会显示文件名 · 文件大小 · 修改日期 · 图像信息;照片带有 EXIF 时,还会一并显示拍摄时间 · 相机 · 镜头 · 曝光 · 焦距 · 闪光灯 · 位置 (GPS)。只显示有值的行。双页显示时,两张图的信息分别显示在各自的半边。再按一次 `Tab` 即隐藏。

**打开 iPhone 照片(HEIC)、相机 RAW 或 Photoshop 文件**
HEIC · AVIF · JPEG XL,Canon · Nikon · Sony · Olympus · Pentax · Panasonic 的 RAW,以及 Photoshop PSD,都能像其他图片一样拖进来打开。照片会按拍摄方向正确打开,带有色彩配置文件时显示原本的颜色。

**查看动态 GIF · WebP**
在单页显示中打开动态 GIF · APNG · WebP 会直接播放。双页显示和条漫模式只显示第一帧。

**边看边整理照片**
在不想要的照片上按 `Delete` 会弹出确认窗口,点 **是** 就移到回收站。不是彻底删除,可以从回收站恢复。嫌确认窗口麻烦,可以关闭 **设置 → 常规 → 删除文件前再次确认**。此操作只作用于文件夹中的文件,不会改动压缩包里的图片。

**从上次看到的地方继续**
直接运行 WorldView,就会打开上次查看的列表和页面。没看完的漫画也会从那一页接着看。最近打开的 5 项可在右键 → **最近的文件** 中选择。如果想每次都从空窗口开始,请关闭 **启动时打开上次的文件**。

**全屏欣赏**
按 `Enter` 或点击标题栏的 `[]`,会进入连任务栏也一起覆盖的全屏。按 `Esc` 或 `Enter` 返回。全屏时按 `Esc` 不会退出程序,只会退出全屏。

**置于其他窗口之上作参考**
点击标题栏的图钉即开启 **总在最前**,使用其他程序时 WorldView 也不会被遮住。适合对照参考图作画,或把文档放在旁边工作。

**并排比较两张图片**
再运行一个 WorldView,新窗口会稍微错开打开,不会与前一个窗口重叠。把窗口并排放好比较即可。

**在最后一页之后回到开头**
默认情况下,在最后一页继续翻页会停下,并在画面上提示 `已经是最后一张图像`。想像幻灯片一样循环查看,请把 **设置 → 查看 → 在第一个/最后一个文件时** 改为 **回到开头**。

**双击图片时用 WorldView 打开**
在 **设置 → 文件关联** 中勾选要用 WorldView 打开的扩展名(也有 **全选**)。可选 JPG · PNG · GIF · WebP · TIFF · BMP · TGA · PSD · JPEG 2000 · DDS · PCX · PDF · CBZ · CBR,同一格式(`.jpg` `.jpeg` `.jfif`)合为一格。格子旁出现 **未应用** 表示 Windows 正优先使用其他程序 —— 点击该标记会打开此扩展名的默认应用选择窗口,选择 WorldView 即可。卸载 WorldView 后,关联也会恢复原状。

**按自己的习惯修改快捷键**
在 **设置 → 快捷键** 中点击要修改的操作的按键格,然后按下新键。也支持 `Ctrl` · `Shift` · `Alt` 组合。`Backspace` 恢复默认值,`Esc` 取消。其他操作已在使用的键不会被接受,并会提示它被哪个操作使用。

| 操作 | 默认按键 |
|---|---|
| 适应窗口 · 原始大小 · 适应宽度 · 适应高度 | `1` · `2` · `3` · `4` |
| 顺时针旋转 90 度 | `R` |
| 显示/隐藏图像信息 | `Tab` |
| 切换全屏 | `Enter` |
| 打开文件 · 打开文件夹 | `O` · `Ctrl`+`O` |

上一页/下一页(`PageUp` `PageDown`)、第一页/最后一页(`Home` `End`)、放大/缩小(`+` `-`)、回收站(`Delete`),以及方向键 · `Space` · `Esc` 是固定的。

**移动窗口和调整大小**
拖动图片外的空白处,或拖动适应窗口显示的图片,即可移动窗口;拖动边缘可调整大小。用鼠标中键拖动也能移动窗口。窗口的位置和大小会被记住,下次在同一位置打开。

**找到当前文件所在位置**
右键 → **在资源管理器中显示**,会打开资源管理器并选中该文件。重命名或复制文件时很方便。

**让画面更简洁**
在 **设置 → 查看** 中关闭 **显示滚动条** 和 **显示左右箭头按钮**,图片上浮现的东西就会减少。关闭后仍可用滚轮 · 方向键 · 拖动同样地移动和翻页。

在 **设置** 中更改的值,以及在查看菜单中选择的缩放和显示方式,都会自动保存,下次启动时继续使用。

|---|---|
